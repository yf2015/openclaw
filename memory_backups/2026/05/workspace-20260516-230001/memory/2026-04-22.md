## GitHub Sync - SSH 认证 + Push Protection 问题解决

### 问题背景
- GitHub 推送报 `GH013: Push cannot contain secrets`
- 原因：remote URL 是 `https://ghp_TOKEN@github.com/...`，token 暴露在 URL 中
- VPS 443 端口直连 GitHub 超时，但 api.github.com (443) + SSH 端口 22 均正常

### 解决过程
1. 生成 SSH key：`ssh-keygen -t ed25519`（路径 `/root/.ssh/id_ed25519`）
2. 测试 SSH： `ssh -T git@github.com` → Permission denied（当时 key 未添加）
3. 发现 SSH 22 端口可用，只是 HTTPS 443 被间歇性阻断
4. 手动改 remote URL 为 SSH 格式后，强推成功：`git push --force`
5. **教训**：强推抹掉了 GitHub 历史，commit `7503bbc` 等被删除
