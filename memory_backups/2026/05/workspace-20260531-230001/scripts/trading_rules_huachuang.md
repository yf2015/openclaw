## ✅ 买入规则（必须同时满足）

### 买入条件A：第一批买入（底仓）
开盘后30分钟内，满足以下**任意一项**：
1. 价格回调到 **640~650** 区间，出现**锤子线**（下影≥实体2倍）
2. 价格回调到 **640~650** 区间，出现**阳包阴吞没形态**（看涨吞没）
3. 开盘在 **618~640** 区间震荡，15分钟内不破618且出现**锤子线/吞没**

### 买入条件B：第二批买入（加仓）
第一批已持仓，且满足：
1. 价格在 **620~640** 区间出现 **启明星形态**（底部星线+阳线确认）
2. 或回调到 **620~630** 区间出现 **锤子线+吞没双重确认**
3. 成交量必须**放大**（超过前5日平均量能的80%）

### 禁止买入（任何时候）
- ❌ 开盘高开>5%不追
- ❌ 已经出现十字线/h黄昏星/h流星形态不追
- ❌ 远离5日均线超过10%不追（等回调）
- ❌ 跌破600不买入（趋势破坏）
- ❌ 跌幅超过-5%且无企稳不补仓

## 🔴 止损规则（红线，触达必须执行）

```
硬止损：600（跌破必须走，不讨论、不犹豫）
移动止损：持仓后价格跌破640 → 减1/3
          持仓后价格跌破620 → 再减1/3
          持仓后价格跌破600 → 全清
```

**《日本蜡烛图技术》原著原则：**
> *保护资本永远第一位。错误时减少损失，正确时让利润奔跑。*

## 📊 趋势判断标准

```
上升趋势（做多）：
  - 5日均线>20日均线>120日均线（多头排列）
  - 价格>5日均线
  - 阳线数量>阴线数量（最近5根）
  - 成交量整体放大

下降趋势（不做多）：
  - 价格<5日均线
  - 连续2根阴线且无企稳
  - 跌破重要支撑位

震荡（观望）：
  - 5日均线走平
  - 价格在±3%区间反复
```

## ⚠️ 核心原则（铁律）

1. **不抗单** — 止损线是红线，触及必须执行
2. **不重仓** — 最大80%仓位，留20%现金
3. **不臆测** — 形态没出现就不动，不猜涨跌
4. **不追高** — 高开>5%等回调，不开盘追入
5. **记录每笔** — 每次买卖记录时间、价格、形态依据
